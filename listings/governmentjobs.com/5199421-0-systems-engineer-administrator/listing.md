Join the City of Pasadena’s award-winning Department of Information Technology as a Systems Engineer and be part of an exciting team that enables technology to improve the lives of everyone in the City.  As a member of the team, you’ll be responsible for implementing and administering critical technology systems that support services to City staff and the public. The opportunity includes the following:
Designs and engineers enterprise client infrastructure systems supporting over 2,000 City employees, with a focus on scalability, security, and intelligent automation.
Administers and troubleshoots cloud and on-premise client infrastructure platforms and services, leveraging AI-powered monitoring and predictive analytics to proactively identify and resolve issues.
Provides technical guidance and support to application teams, service desk staff, and technical partners, while exploring emerging technologies such as machine learning and automation frameworks to enhance operational efficiency.

Essential Functions

The major responsibilities of this position are listed below. For more detailed information, please review the
Systems Engineer/Administrator job description.
Performs client infrastructure systems engineering and administration for enterprise endpoint platforms and supporting services, including Microsoft Intune, Microsoft Endpoint Configuration Manager (SCCM), Microsoft 365, Microsoft Teams, Active Directory, Microsoft Entra ID (Azure Active Directory), Group Policy, AppSense, application delivery systems, and enterprise desktop environments, while implementing modern, cloud-integrated and AI-enabled automation solutions such as zero-touch provisioning, self-healing systems, and proactive monitoring to improve reliability, security, and user experience.
Engineers, administers, and supports enterprise client platform infrastructure, including endpoint management systems, device compliance and security baselines, operating system deployment, software packaging, patching frameworks, and automation and scripting solutions using PowerShell.
Monitors and supports client security and compliance platforms; participates in vulnerability assessments, endpoint security integrations, certificate-based services (PKI), and remediation of desktop and collaboration platform risks.
Participates in the planning, design, testing, upgrade, and lifecycle management of enterprise client infrastructure solutions; evaluates and recommends endpoint hardware, operating system standards, collaboration platforms, and client-facing software technologies.
Performs systems administration and engineering functions for enterprise collaboration and productivity environments, including Microsoft 365, Microsoft Teams, email and messaging systems, identity services, and integrated client communication platforms.
Administers and supports core client-facing infrastructure services, including Microsoft File and Folder Services, Microsoft Print Services, DNS, DHCP, enterprise monitoring platforms, and related client infrastructure technologies.
Supports client data protection and recovery processes, including endpoint data protection strategies, profile and user-environment recovery, and enterprise tools that safeguard desktop and collaboration service data.
Manages the deployment of desktop applications locally and through enterprise configuration and management platforms, addressing issues related to multiple software versions, packaging technologies, operating system compatibility, security protocols, and interoperability within a complex enterprise client environment.
Provides technical assistance to application development and business teams by supplying client infrastructure guidance related to access, configuration, data locations, identity integration, and software requirements; supports application installation, testing, and troubleshooting.
Maintains up-to-date technical knowledge by attending educational workshops, reviewing professional publications, establishing personal networks, and participating in professional associations.
Provides after-hours and/or on-call support; conducts remote problem diagnosis and resolution; and notifies supervision of action required if remote remediation cannot be achieved.
